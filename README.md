# Отклик принят

Пиксельная пародия на поиск первой работы в IT и маркетинге. Листайте абсурдные вакансии, отвечайте ИИ-рекрутерам и узнайте, хватит ли 48 лет стажа дайвером для позиции джуна. Зарплата — сосиска.

## Установка

[Скачать APK v1.1](downloads/Otklik-Prinyat-v1.1.apk?raw=1) для Android 6.0 и новее. Откройте скачанный файл на смартфоне.

## Сборка

Нужны Windows, PowerShell, JDK 21 и Android SDK с пакетами `platforms;android-36.1` и `build-tools;36.1.0`.

```powershell
.\build.ps1
```

Скрипт использует `JAVA_HOME` и `ANDROID_HOME`. Пути можно передать явно через `-Jdk` и `-Sdk`. APK без подписи появится в `build/otklik-unsigned.apk`.

Для установочной сборки укажите собственное хранилище ключей и псевдоним ключа. Пароль хранилища задайте в переменной окружения `OTKLIK_KEYSTORE_PASSWORD`.

```powershell
.\build.ps1 -Keystore .\my-key.p12 -KeyAlias otklik
```

Подписанный файл появится в `build/otklik.apk`. Android принимает обновления поверх установленной версии, когда обе сборки подписаны одним ключом.
